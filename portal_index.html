Setup Guide — Brevo (5 minutes)
1. Go to brevo.com → Sign up free
2. Verify your email, skip the tutorial
3. Go to SMTP & API → API Keys
4. Click Generate a new API key → name it "ANOSagent"
5. Copy the key and paste below
6. Go to Senders → Add a sender → verify your domain (e.g. info@yourdomain.com)
Setup Guide — Mailgun (5 minutes)
1. Go to mailgun.com → Sign up free
2. Add your domain (e.g. mg.yourdomain.com) and verify DNS records
3. Go to Domain Settings → SMTP Credentials
4. Copy the API key and domain below
5. Add an authorized recipient (your email) for testing
Common SMTP Settings
• GoDaddy Workspace: smtpout.secureserver.net, port 465, SSL
• Google Workspace: smtp.gmail.com, port 587, TLS — use App Password
• Microsoft 365: smtp.office365.com, port 587, TLS
• Zoho Mail: smtp.zoho.com, port 587, TLS
• cPanel/Web Host: mail.yourdomain.com, port 465, SSL

Client Portal Custom Domain

Give your clients a fully branded login URL like client.kwsnowco.ca/client or portal.mammothtreeco.ca/client. Point any domain or subdomain you own to our servers, and your clients see your branding — not ANOSagent's.

Branding

DNS Setup (any provider):
1. Go to your DNS provider (Cloudflare, GoDaddy, Namecheap, etc.)
2. Add a CNAME record: client.yourdomain.com → app.anos.ca
3. Wait 5–60 minutes for propagation
4. Your portal is live at https://client.yourdomain.com/client
5. Share that link with your clients — they'll see your business name on the login page

SSL: We automatically provision a free SSL certificate for your domain once DNS points to us.
